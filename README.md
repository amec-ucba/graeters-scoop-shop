# 🍦Graeter's Scoop Shop

The Graeter's Scoop Shop site is already built. In this exercise you add the finishing details with positioning,
z-index, pseudo-classes and pseudo-elements: a sticky category nav, pinned card badges, hover and focus states, a
striped price table and decorative quotation marks.

> folders are setup files that keep assignments consistent. Leave them alone.

## 📂 Where Your Files Go

The pages and starter styles are already in place. Write all of your CSS in **`css/details.css`**. The comment at the
top of that file lists each task. The only HTML you add is the card badges in `index.html`.

```
graeters-scoop-shop/
├── index.html        Flavors page (add the card badges here)
├── about.html        Our Story page
├── css/
│   ├── base.css      Provided styles and color variables. Don't edit.
│   └── details.css   Your work goes here
└── images/           Logo and photos
```

Keep `index.html` in the root folder. GitHub Pages publishes from the root, so moving it will make your site 404.

## 🤖 AI Policy

Work on this assignment must be your own. Do not use AI coding assistants — including
GitHub Copilot, Cursor, ChatGPT, Claude, or JetBrains AI Assistant — to generate,
complete, or rewrite your code.

You should be able to explain any line of your submission. You may be asked to do so.

This repo includes a `.noai` file, which disables JetBrains AI Assistant for the project
in IDEs like WebStorm. Leave it in place. It is a reminder of the policy above, not a
substitute for it — following the policy is still your responsibility.

> [!NOTE]
> The `.noai` file does **not** turn off WebStorm's local Full Line code completion. Turn that
> off yourself as part of the [one-time setup](.github/WEBSTORM_SETUP.md) (step 5).

> [!CAUTION]
> Late or missing submissions are graded on what is in the pull request at the deadline, so push your final commits
> before you submit.
